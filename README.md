# ✂️ Salon & Barbershop Appointment Booking Form

A modern, responsive, and user-friendly appointment booking interface designed for salons, barbershops, and beauty studios. This project demonstrates front-end development skills through a clean design, organized booking form, service selection, and appointment scheduling interface.

## 📌 About the Project

The Salon Appointment Booking Form is a front-end web development project created to simplify how customers request salon and grooming appointments.

The interface allows users to enter their contact information, select a service, choose a preferred stylist, and request an appointment date and time. A booking summary helps users review their selections before submitting the form.

The project focuses on usability, responsive design, form validation, and a professional beauty-studio aesthetic.

## ✨ Features

- **Customer Information:** Form fields for customer contact details.
- **Service Selection:** Options for salon and grooming services.
- **Service Details:** Displays example prices and estimated service durations.
- **Stylist Selection:** Allows users to choose a preferred stylist.
- **Appointment Scheduling:** Date and time selection.
- **Appointment Preferences:** Options for supported appointment types.
- **Booking Summary:** Helps users review their selected details.
- **Form Validation:** Basic validation for required fields and user input.
- **Responsive Design:** Layout adapts to desktop, tablet, and mobile screens.
- **Modern UI:** Clean styling, organized sections, and a beauty-inspired color palette.

## 🚀 Getting Started

Follow these steps to run the project on your computer.

### Prerequisites

- A modern web browser.
- Visual Studio Code or another code editor.
- Git, if you want to clone the repository.

### 1. Clone the Repository

```bash
git clone https://github.com/Regalson001/Salon-Appointment-Booking-Form.git
```

### 2. Open the Project Folder

```bash
cd Salon-Appointment-Booking-Form
```

Open the folder in Visual Studio Code:

```bash
code .
```

You can also open the folder manually through Visual Studio Code using **File → Open Folder**.

### 3. Run the Project

Open `index.html` in your browser.

For a more convenient development experience, install the Live Server extension in Visual Studio Code and select **Open with Live Server**.

No build tools or package installation are required for the basic project.

## 🧭 How to Use

1. Open the booking form in your browser.
2. Enter the requested customer information.
3. Select your preferred salon or grooming service.
4. Choose a stylist if the option is available.
5. Select your preferred appointment date and time.
6. Review the booking summary.
7. Complete the required fields and submit the form.
8. Follow the on-screen feedback.

**Note:** This is a front-end demonstration. Submitting the form does not create a confirmed appointment or send information to a real salon.

## ⚠️ Current Limitations

This project demonstrates a front-end booking interface and does not include a complete booking backend.

- Bookings are not stored in a database.
- Appointment requests are not sent to a salon.
- Stylist availability is not checked in real time.
- Appointment slots are not reserved.
- Email and SMS notifications are not implemented.
- Online payments are not supported.
- Browser-side validation does not replace server-side validation.

A successful demo submission should not be interpreted as a confirmed appointment.
